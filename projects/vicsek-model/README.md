# Vicsek 模型的相分离复现

用 Python 与 C++ 两条实现线，复现 Solon、Chaté 与 Tailleur,
*From Phase to Microphase Separation in Flocking Models: The Essential Role of Nonequilibrium Fluctuations*,
**PRL 114**, 068101 (2015) 的 Fig 2(a) 与 Fig 3(c,d)。

站点上的项目页：`index.qmd`（渲染后为 `index.html`）。

## 1. 定位

复现目标不是"跑一个 Vicsek 模型看看"，而是回答三个具体问题：

1. **相图能不能对上。** 论文的 binodal 相图（$\rho_\ell(\eta)$ 与 $\rho_h(\eta)$）在四个密度上的窗口中点，能不能用自己的代码复现到 0.01？
2. **滞后回线能不能复现。** $\eta=0.4$ 下"气体 ↔ 微相分离"（Fig 3(c)）与"微相分离 ↔ 极性液体"（Fig 3(d)）这两条回线，跃变位置和幅度对不对？
3. **定量差在哪里、为什么差。** 哪些是算力不够导致的未平衡，哪些是协议选错，哪些是真物理。

**结论先行**：定性全部复现；定量上相图窗口中点吻合到 0.01，Fig 3(c) 跃变位置与幅度在 0.05–0.1 以内，Fig 3(d) 的平台与高密度端对上；气体侧 binodal 在 $\eta\ge0.4$ 偏高 20–40%，Fig 3(d) 的崩塌位置偏早且偏平缓——原因是算力受限下缩减了 $L_\perp$ 与步数，不是物理。

**为什么重写代码**：这篇论文的相图对噪声约定（角噪声 vs 矢量噪声）、初态协议、盒子纵横比都很敏感。只有代码是自己写的、而且有两套独立实现互相对齐，才能确定复现的是论文里那条线。

## 2. 模型方程

角噪声（scalar / angular noise）Vicsek 模型，对应论文式 (1)。所有粒子用 $t$ 时刻的信息**平行更新**：

$$
\theta_i(t+1)=\mathrm{Arg}\Big(\sum_{j\in S_i}\mathbf{v}_j(t)\Big)+\eta\,\xi_i,
\qquad
\mathbf{x}_i(t+1)=\mathbf{x}_i(t)+v_0\,\mathbf{e}_i(t+1)\pmod L
$$

- $S_i$：与粒子 $i$ 距离 $\le R$ 的所有粒子（**含自身**），周期边界取最小镜像约定；
- $\xi_i$：$[-\pi,\pi]$ 上均匀分布的随机角，噪声幅值为 $\eta\pi$，$\eta\in[0,1]$；
- 标准参数：$v_0=0.5$、$R=1$、$\Delta t=1$；初态为随机位置 + 随机取向（"从无序出发"）。

### 术语辨析（本文档只写这一次）

同一篇文献里 "vectorial noise" 和 "angular noise" 常被混着写，但它们是两个不同的模型。按 Ginelli & Chaté, *EPJ ST* **225**, 2099 (2016)：

| 名称 | 定义 | 出处 |
|---|---|---|
| **scalar / angular noise** | 随机角 $\eta\xi_i$ 加在邻居速度**和的辐角**上 | 该文式 (2)，即论文式 (1)，即本项目的实现 |
| **vectorial noise** | 随机矢量在归一化**之前**加到邻居速度**和**上，幅值正比于邻居数 | 该文式 (6) |

两者渐近性质相同、有限尺寸行为有差异。论文 Fig 2 / Fig 3 用的是角噪声版本，本项目与之对齐，因此 $\eta$ 刻度可以直接和论文比较。**对照文献数值时不要混用。**

### 观测量

| 观测量 | 定义 | 用途 |
|---|---|---|
| 序参量 | $\varphi=\lvert\sum_i\mathbf{v}_i\rvert/(Nv_0)$ | 有序相 ~1，无序相 $\sim1/\sqrt N$ |
| 横向密度方差 | $\Delta\rho_\parallel^2$（沿全局运动方向做横向平均剖面的方差） | Fig 3(d) 的滞后回线纵轴 |
| 带数 | $n_b$（对齐后时间平均剖面的峰计数） | 判断是否处于干净带态 |
| 剖面谷值 / 峰值 | 同一条剖面的 $\min$ / $\max$ | 分别给出 $\rho_\ell(\eta)$ 与 $\rho_h(\eta)$ 的候选读数 |

```powershell
      code\vicsek_ramp.cpp -o code\vicsek_ramp.exe
```

### 跑

```bash
python code/vicsek.py --selftest             # 自检：邻域搜索 + 定性物理
python code/scan.py --dry-run                # 预览网格任务清单与预算
```

C++ 的行/下行 ramp（论文规格 400×400）：

```powershell

.\code\vicsek_ramp.exe --Lx 400 --Ly 400 --eta 0.4 --rho-start 2.0 --rho-end 4.6 --drho 0.3 `
  --steps 4000 --snap-every 100 --pre-equil 4000 --nprof 400 --threads 4 --seed 1 `
```

$$\frac{m_b}{L_\perp}=\underbrace{w_{\rm eff}}_{\div 1.71}\times\underbrace{\Delta\rho}_{\div 1.15},\qquad 1.71\times1.15=1.96\ \checkmark$$

| $\eta$ | $\rho_{\rm gas}$ | $\rho_{\rm peak}$ | $\Delta\rho$ | $w_{\rm FWHM}$ | $w_{\rm eff}$ | $m_b/L_\perp$ | $n_b$ |
|---|---|---|---|---|---|---|---|
| 0.40 | 0.622 | 4.82 | 4.20 | 40.0 | 41.5 | 174.4 | 6 |
| 0.35 | 0.590 | 4.26 | 3.67 | 25.0 | 24.2 | 88.8 | 10 |

## 6. 关键技巧与踩坑

### 6.1 协议本身是结果的一部分（最重要的一条）

同一个状态点（$\eta=0.4$、$\rho_0=2.87$），三种上行支协议给出三个差别很大的 $\Delta\rho_\parallel^2$：

| 协议 | $\rho_0=2.87$ 处 $\Delta\rho_\parallel^2$ | 现象 |
|---|---|---|
| 每点 4000 步、播 2 条带 | 3.56 | 带被压缩（未弛豫），偏高 |
| 每点 8000 步、播 3 条带 | **2.30** | 与论文 2.1 吻合 ✓ |
| 单点充分弛豫（3000+ 步自由演化） | 1.24 | 带展宽、气体密度升到 1.65，偏低 |

**太快 → 压缩偏高；太慢（或固定带数不匹配）→ 展宽偏低**。论文的 2.1 落在中间，对应 ramp 足够慢、使带数能随密度自行调整（论文原话：*"if the ramping is slow enough, they correspond to the nucleation and vanishing of a single band"*）。播种带数应按**自然带数** $n_b=L_\parallel(\rho_0-\rho_{\rm gas})/\mu$ 选取，否则带被压缩——论文自己也提醒过这一点。

### 6.2 小 $L_\perp$ 会人为稳定带

曾据 $L_\perp=48$ 的盒子误得 $\rho_h>5.5$：30000 步 span 从 6.35 到 4.16 无趋势衰减（均值 5.03）。同条件下 $L_\perp=200$ 给出 5.26 → 3.56 → 2.39 单调衰减，说明带其实在溶解。**判据要用带稳定性，不能用剖面峰值。**

### 6.3 跨 $\eta$ 比较必须配平液相比

- 配平"过剩密度" $\rho_0-\rho_{\rm gas}$ → 只在**固定 $\eta$** 下正确（这是 Fig 2(b) 与 Fig 3(a,b) 塌缩用的变量）；
- 跨 $\eta$ 必须配平**液相比**（杠杆定则）：$\varphi_{\rm liq}=(\rho_0-\rho_\ell)/(\rho_h-\rho_\ell)=\text{const}$。

用 $\varphi_{\rm liq}=0.39$ 从相图反解：

| $\eta$ | $\rho_\ell$ | $\rho_h$ | 正确的 $\rho_0$ |
|---|---|---|---|
| 0.40 | 0.606 | 3.98 | **1.92** |
| 0.35 | 0.378 | 2.85 | **1.34** |
| 0.30 | 0.212 | 2.00 | **0.91** |

（$\rho_\ell,\rho_h$ 由 `page.get_drawings()` 从论文 Fig 2(a) 的矢量点插值得到，并用论文自己的"三倍"说法交叉验证：$(1.93-0.606)/(1.05-0.606)=3.0$ ✓）

### 6.4 C++ 侧的两个坑

1. **libm 调用**：`std::nearbyintf` / `std::floorf` 未被内联时是真正的函数调用；内层循环每对候选粒调 2 次 → 6600 万次/步，正好解释实测的 1.03 s/步。改成 `fast_round()` 与条件回绕后 **12.8×**（4 线程 744 → 58 ms/步）。
2. **自己写的查表 bug**：把 `ang×NB/(2π)` 当作"圈数比例"后又乘了一次 `NB`，等效把噪声角放大 6.28 倍并打乱 → 任意 $\eta>0$ 都变成随机旋转。**发现线索**：$\eta=0$ 极限测试给出 $\varphi=1.0000$ 且所有粒子指向 $+x$——这正是"零邻居回退分支"的特征签名（诊断打印随后确认邻居数其实正常，7.29/粒子）。

### 6.5 Python 侧的两个坑

1. **排序后"朝向 ↔ 位置"错配（真 bug）**：把状态存成 $\theta$，在单元计数排序**之前**算好 $(\cos\theta,\sin\theta)$，排序后用新槽位去索引旧顺序的三角函数值 → 张冠李戴。修法（照搬 `vicsek_ramp.cpp` 的设计）：直接以 $(\cos\theta,\sin\theta)$ 为状态量，scatter 时和位置一起搬运，永不重算。
2. **初态的取向展宽是要害**：

| 初态 | 结果 |
|---|---|
| 随机位置 + **随机朝向** | 跑 12000 步 → 塌成**一个巨团**（峰值 $\rho\approx19$） |
| 按 6 条带密度种子 + **随机朝向** | 跑 10000 步 → **也塌** |
| 按 6 条带密度种子 + **朝向近似对齐（spread $=0.1\pi$）** | **稳定 6 条带** ✓ |

带的形成有明确的成核/弛豫门槛，呼应论文的"临界核"与 Fig 3(c) 滞回环。

### 6.6 其他

- $\eta_c$ 随 $L$ 增大是**物理**（一级相变 + 带相），不是误差；
- $\eta=0$、低密度是退化奇点（无限凝聚，粒子弹道合并、永不达稳态），默认网格已避开；强行加回预期单点耗时约为相邻 $\eta$ 点的 20 倍；
- 邻域搜索的精确性：精确单元列表法 vs 暴力 $O(N^2)$，最大误差 $1.8\times10^{-15}$；致密团簇下自动切到 x 排序循环窗口法，误差 $2.8\times10^{-14}$；
- 复现性：种子由 $(L,\rho,\eta)$ 确定性生成，同参数重跑结果一致。
